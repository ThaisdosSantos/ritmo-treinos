Como funciona a conexão?

A autorização é temporária e fica apenas nesta aba. Quando expirar, conecte novamente. Falhas no envio não apagam o treino: você pode tentar pelo histórico. Sessões anteriores são enviadas apenas quando solicitado.

Ajuda de OAuth e Google Cloud

Habilite a Google Calendar API no Google Cloud e, no cliente OAuth de Aplicativo da Web, inclua https://thaisdossantos.github.io em “Origens JavaScript autorizadas”. Se estiver em modo de teste, inclua seu e-mail nos usuários de teste e permita os pop-ups de autorização.

Onde meus dados ficam salvos?

Treinos, cargas e histórico são armazenados neste navegador e separados por conta Google. O histórico é salvo neste navegador e, após configurar a API, também no MongoDB Atlas.
